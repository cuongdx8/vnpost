# Local secrets

File được Git theo dõi tại đây chỉ gồm README này và secrets.example.json. Credentials thật dùng <environment>.local.json, không đưa lên Git/ZIP source.

File dev.local.json đã được điền từ code được giao, phân loại DEV theo chủ dự án. Chưa xác minh hiệu lực hoặc expiry. Chuyển file riêng khi clone repo mới. Không in nội dung key ra chat/log.
